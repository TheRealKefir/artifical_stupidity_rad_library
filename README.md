# 📚 Artifical Stupidity RAD library

Веб-приложение для умного поиска по книгам с использованием моделей искусственного интеллекта. Позволяет загружать книги, обрабатывать их и получать осмысленные ответы на поисковые запросы.

---

## 🚀 Возможности

* 📥 Загрузка книг (текстовые файлы)
* 🔍 Умный поиск по содержимому
* 🤖 Генерация ответов с помощью AI
* 🗄️ Хранение данных о книгах и запросах
* ⚡ Быстрая работа на локальной базе данных
* 🌐 Возможность подключения к развернутому приложению по ссылке (хостинг)

---

## 🛠️ Технологии

* **Backend:** Flask
* **Frontend:** Vanilla JS (native)
* **AI:** HuggingFace модели
* **Database:** SQLite
* **UI:** HTML / CSS

---

## 📦 Установка

```bash
git clone https://github.com/your-username/your-repo.git

pip install -r requirements.txt

```

## ▶️ Использование

1. Открой приложение в браузере
2. Загрузи книгу
3. Введи поисковый запрос
4. Получи ответ, сгенерированный ИИ

💡 Либо просто перейди по ссылке на развернутую версию приложения (если доступна)
