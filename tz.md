# Техническое задание
## Введение
Данный проект является учебным заданием, целью которого является разработка веб-приложения для умного поиска по книгам с использованием моделей ИИ
## Цели и задачи
Целью данного проекта является создание веб-приложения, которое позволит пользователям эффективно искать информацию в книгах с помощью ИИ. Задачи включают:
1. Разработка интерфейса для загрузки книг и ввода поисковых запросов.
2. Интеграция модели ИИ для обработки текстов и генерации ответов на основе содержимого книг.
3. Интеграция с базой данных для хранения информации о книгах, поисковых запросах и пользователях.
## Требования
1. Веб-приложение должно быть разработано с использованием современных технологий, таких как Flask, js native.
2. Модель ИИ должна быть способна обрабатывать текстовые данные и генерировать релевантные ответы на поисковые запросы.
3. База данных должна обеспечивать надежное хранение информации и поддерживать быстрый доступ
4. Интерфейс должен быть интуитивно понятным и удобным для пользователей.
## Ожидаемые результаты
1. Рабочее веб-приложение, позволяющее пользователям загружать книги
2. Функциональность поиска по книгам с помощью ИИ
3. База данных, обеспечивающая хранение информации о книгах и поисковых запросах
4. Документация по использованию приложения и его функциональности
## Фреймворки и технологии
1. Flask - для разработки веб-приложения
2. js native - для создания интерактивного интерфейса
3. huggingface - для интеграции модели ИИ
4. SQLite - для хранения данных о книгах и поисковых запросах
5. HTML/CSS - для создания пользовательского интерфейса
