## Команды

### Пользовательские команды
- `/start` - Начало работы
- `/menu` - Главное меню
- `/endchat` - Выход из чата с оператором

### Административные команды
- `/admin` - Панель администратора
- `/reply <user_id> <текст>` - Ответ пользователю в чате

## Работа с заявками

### Создание заявки
1. Нажмите "Связаться с оператором" или "Мои заявки" → "Создать заявку"
2. Опишите проблему
3. При необходимости прикрепите фото или документ
4. Получите номер заявки

### Ответ администратора
1. Администратор выбирает заявку из списка открытых
2. Нажимает "Ответить"
3. Вводит текст ответа
4. Пользователь получает уведомление

### Закрытие заявки
Администратор нажимает "Закрыть тикет" после решения проблемы

## FAQ

FAQ реализован с постраничной навигацией (5 вопросов на страницу):
- Навигация по страницам через inline-кнопки
- Возврат к списку вопросов после просмотра ответа
- Автоматическое удаление старых сообщений

## База данных

SQLite с таблицами:
- `tickets` - заявки
- `ticket_messages` - сообщения в заявках
- `bug_reports` - баг-репорты
- `suggestions` - предложения
- `operator_chats` - активные чаты
- `operator_messages` - история чатов

## Безопасность

- Токен бота хранится в `.env` (не в Git)
- ID администраторов в `.env`
- Валидация пользователей по ID
- Проверка прав доступа к административным функциям
